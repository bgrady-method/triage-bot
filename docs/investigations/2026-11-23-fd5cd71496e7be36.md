### Likely cause
Code bug in Method.Data.OData.ODataQueryBuilder.GetConstantValue: unquoted OData date literals arrive as Microsoft.OData.Edm.Date and go to Dapper unconverted. Dapper throws NotSupportedException, and the REST API returns 500 instead of either honoring the filter or returning 400. Any customer integration that filters a date column with standard OData v4 date syntax fails.
