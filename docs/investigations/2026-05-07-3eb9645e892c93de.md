### Likely cause
ms-sync-util service is down or its IIS pool has failed, making `GetSyncWidgetInfoAsync` unreachable through the gateway for all accounts. The sync widget status display is broken for all users who load a screen containing a sync widget. With no new deploys and no code changes, this is most likely an infrastructure event (IIS pool crash/hang, host disk/memory pressure, or a dependency failure). The persistence of the issue since 08:08 UTC without resolution suggests either the team hasn't had bandwidth to act on the DMs, or there is a deeper infrastructure issue preventing recovery.
