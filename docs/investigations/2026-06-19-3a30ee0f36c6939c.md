### Key findings
- **The loud signal is a red herring.** 84 "JWT Retrieval Failed" across PROD-NEW-04/5/6 (baseline 24h ago = 0) is **100% WindowsPowerShell synthetic Centreon probes** — the benign, well-documented `ki-2026-05-29-methodsession-getaccountbysubdomain-nre` pattern. Underlying NRE: `MethodSessionService.GetAccountBySubdomain()` dereferences null because `account/v3/overview?subdomain=<node-hostname>` returns 404 (no real account for a probe). Zero real browsers, zero real-account 404s.
- **The real incident left no backend fingerprint.** During 12:50–13:06Z, gateway, ms-authentication-api, signin, and the production apps pools were all at baseline for *real* (non-probe, non-mobile) traffic. No 5xx storm, no latency breach, no error-rate monitor fired.
- **Monitoring gap:** the customer-facing blank-screen incident was caught by **humans only**. No Datadog monitor fired. The `[Synthetics] [Release] Sign in to Method` check has been No-Data since 2026-05-06.
- **SWAT auto-investigation mis-targeted:** it probed host NEW4's `nonprod` app pool (returned healthy) — not the production `methodportal.com` pool, and not the flapping behaviour users saw across the LB.
- **Timing coincidence:** both the synthetic NRE storm and the human incident began ~12:50Z (storm was 0 before). Suggests a common brief trigger (deploy / node recycle / config change) that gave real users a transient client-side blank screen that self-healed and tripped the synthetic probes — but the trigger is not visible in available backend telemetry.

### Likely cause
Real customer-facing intermittent blank-screen-on-login, ~12:50–13:06Z, largely self-recovered. Most consistent with a **transient client-side / session-cookie / SPA-bootstrap failure** (Nelson: re-auth fixed it, refresh didn't), possibly triggered by a brief platform event ~12:50Z. **Root cause not determinable from backend telemetry** — needs Datadog RUM (client-side errors) and confirmation from devops of what changed at ~12:50Z. The concurrent JWT/Centreon storm is benign synthetic noise and should not be chased.
