### Likely cause
Load-induced thread-pool starvation in method-mobile-notifications-api. The sync Redis HMGET in `CacheMapperProvider.Get` (and the shared Twilio `RequestValidator`) fails under the burst of Twilio status callbacks a bulk SMS send produces. This cycle could not re-confirm it from stack traces (ES 401, no DD Logs). The attribution rests on an identical metric fingerprint: the same resource pair, the same service-only Redis errors, and the same fan-out ratio of about 2.4×.
