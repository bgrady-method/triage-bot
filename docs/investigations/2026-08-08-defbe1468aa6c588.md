### Likely cause
`WKNSUndoManager` (the native undo-manager backing the app's `WKWebView`, which per the repo's CLAUDE.md wraps the main Method CRM web interface) entered an invalid state from mismatched nested `beginUndoGrouping`/`endUndoGrouping` calls, causing an uncaught `NSInternalInconsistencyException` and app termination. This is a known class of iOS `WKWebView` bug, typically triggered by rapid or overlapping text-editing/undo interactions inside the wrapped web content (e.g. a Screen/Grid editor field). Single occurrence — not yet reproducible on demand, but the exception message is specific enough to be a real, filable defect signature rather than noise.
