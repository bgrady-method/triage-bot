- `connectAnimatedNodes: Animated node with tag (parent) [N] does not exist` is a known React Native `Animated` API failure mode — it fires when native module code tries to operate on an animated node graph after the owning component has already unmounted/torn down the graph (a teardown race). This is a library-level (React Native / Reanimated bridge) race condition much more often than it is application business-logic; it can be triggered by app code that doesn't clean up animation refs on unmount, but the message itself doesn't pin a specific Method screen or action.

### Likely cause
An isolated React Native `Animated` API teardown race on a single mobile session — most likely a library/bridge-level timing issue rather than a new server-side regression. Consistent with the pattern from the two prior occurrences of this monitor: low-volume, single-event fires, different crash signature each time, no systemic pattern yet.
