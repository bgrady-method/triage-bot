## Lessons / follow-up
1. **ES wildcard tokenization trap:** `Error.keyword:*<phrase with spaces>*` can match unrelated documents whose OTHER fields (e.g. JSON response bodies logged verbatim in `message`) contain overlapping tokens. Always cross-check a suspiciously large wildcard-query count against an exact-phrase or unique-substring (e.g. a GUID/CLSID) query before reporting magnitude — this cycle a wildcard search overstated a real finding by ~150x (1174/day → actual 1/day, 100% single-account).
2. Flag `TexedoTechnologiesInc`'s recurring `ThirdPartyCreateAccount` COM failure to Ben — worth a one-time host-level check of `PROD-CLASSIC-01`'s COM registration for CLSID `F8D07B72-B4B4-46A0-ACC0-C771D4614B82`, and worth asking the customer/support team whether they're aware of a broken third-party-account-linking action.
