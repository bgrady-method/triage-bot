### Likely cause

Chronic per-account QBO sync-throttle on `sacredstudiosinc`. The Method.SyncEngine has a per-account `RedLockConcurrencyGate` (Redis-backed distributed lock) limiting parallel sync slots; sacredstudiosinc keeps hitting `MethodSurpassedLowConcurrent` because either (a) the account's sync workload exceeds its tier's slot budget, (b) the slot budget is misconfigured for the account's QBO entity volume, or (c) there's a lock-leak (sync started, never released the slot, slot count drains). The recurrence at 30-min cadence today suggests a stuck or slow sync that periodically retries.

Concurrent ERR_KEY_CHAIN burst is mechanically unrelated — different host (PROD-NEW6 vs PROD-UTILITY-02/03), different code path, different account, single-device source. Document but don't conflate.
