### Likely cause
Code bug in runtime-core `Method.Data.OData.ODataQueryBuilder.GetConstantValue`. Unquoted OData v4 date literals parse as `Microsoft.OData.Edm.Date` and get bound to Dapper unconverted. The REST API then returns 500 instead of honoring the filter or returning 400. Any customer integration that loops on a standard OData date filter produces a burst that trips 70171778.
