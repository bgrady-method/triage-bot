This is a corrupted or version-incompatible saved-report-layout issue scoped to those 2 accounts' specific reports, not a service-wide regression — consistent with the error-rate metric only marginally/inconclusively crossing threshold (few accounts hitting it repeatedly inflates the ratio on a low-traffic endpoint).
