### Likely cause
`oauth_token` is the OAuth2/IdentityServer4 token store (issued JWTs, refresh tokens, authorization codes). Likely root cause for the 6 TB size: **no automated expired-token cleanup**, so revoked/expired token rows accumulate indefinitely. The current size doesn't break anything today, but it has downstream implications:
- Backup duration scales with DB size — overnight backup window may eventually overrun.
- Restore time grows correspondingly.
- Mongo working-set / index size implications for hot oauth lookups.
