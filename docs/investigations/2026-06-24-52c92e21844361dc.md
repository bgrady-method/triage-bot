### Likely cause
The "New/Edit Work Orders v2" screen in synergyengineering's "Work Orders - Synergy" app is firing the "Calc Total Hours" AppRoutine with `arWOID = 0` (an unselected/zero work-order id) — most likely a screen-load or new-record event bound to run the routine before a work order exists, or the routine itself was deleted/disabled. Either way the engine rejects it as `UnprocessableRoutine`. This is a per-account configuration/data problem, not a platform regression.
