- **Historical context:** KB first recorded 2026-06-17 at 396/h; today's 63min window = ~43/h (89% reduction from peak — playbook's account timezone fix likely applied for the original high-volume accounts thestoragegroup/supplyshield)
- **Mechanism:** `Com.Method.Utils.TimeZoneLookup.GetSystemTimeZoneById()` (legacy-common-core) passes an IANA timezone id directly to `TimeZoneInfo.FindSystemTimeZoneById()` on Windows Classic servers. Windows does not recognise IANA ids (e.g. `America/New_York`); it expects `Eastern Standard Time`. The method's default case throws `TimeZoneNotFoundException` unhandled, which propagates as an Error log.
- **Reasoning → KIR:** Pattern, hostname, and Error.keyword exactly match KB entry. Gate was open (last_notified_at=null — never notified despite being in KB since 2026-06-17).
